---
title: Connect your agent
description: One deployed endpoint, one personal key, and explicit account selection.
---

## 1. Get your personal key

In Quill, open **Settings → Your agent** and copy the key. It is personal: each approved member uses their own key. The key can manage the private shared accounts, but never reveals either account's X credentials.

## 2. Add the deployed MCP

Use your Quill backend domain with `/mcp` appended:

```json title="MCP configuration"
{
  "mcpServers": {
    "quill": {
      "url": "https://<your-quill-backend>/mcp",
      "headers": {
        "Authorization": "Bearer <your-personal-quill-key>"
      }
    }
  }
}
```

The endpoint uses Streamable HTTP. It is deployed alongside the Quill backend, so there is no local CLI, local profile directory, or computer that needs to stay running.

## 3. Start with status

Ask the agent to call `get_quill_status`, then `list_managed_accounts`. Before drafting, scheduling, uploading media, or editing an Article, it must choose one returned `accountId` and pass it explicitly. Then it can read that account's `get_profiles` before proposing copy.

## Key safety

Treat the key like a password. Do not paste it into a public prompt, shared document, or browser extension. If a key is exposed, rotate it from Quill Settings.

Each MCP key belongs to one private Quill member. Call `list_managed_accounts`, then pass the selected `accountId` to every account-specific tool. X credentials are never returned by MCP.

## `get_quill_status`

**Read tool.** Return the authenticated Quill account, connected X account, active queue counts, and total captured research count. Call this first.

_No input._
## `list_managed_accounts`

**Read tool.** List the X accounts this MCP key may manage. Use the returned account ID for every content, media, scheduling, profile, Article, CTA, or repost action.

_No input._

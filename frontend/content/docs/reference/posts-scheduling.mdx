Each MCP key belongs to one private Quill member. Call `list_managed_accounts`, then pass the selected `accountId` to every account-specific tool. X credentials are never returned by MCP.

## `create_draft`

**Write tool.** Create a private post, reply, quote, media post, or thread draft. This never publishes. Use mediaAssetIds for owned media stored through Quill.

```json title="Input schema"
{
  "type": "object",
  "properties": {
    "accountId": {
      "type": "string",
      "format": "uuid",
      "description": "Target managed X account ID. Call list_managed_accounts first; this is required for every account-specific action."
    },
    "text": {
      "type": "string",
      "minLength": 1,
      "maxLength": 25000
    },
    "quotePostId": {
      "type": "string",
      "minLength": 1
    },
    "replyToPostId": {
      "type": "string",
      "minLength": 1
    },
```
